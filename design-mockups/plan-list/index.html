frontend/ — Plan checklist redesign

6 mockups for the plan-list UI

The current design (frontend/src/main.js's renderPlanChecklist) drills one tab-row per depth level, replacing the previous level each click — so seeing 1, 1.2, and 1.2.1 together means clicking back and forth. These six explore different ways to make the hierarchy actually visible. All use the same mock plan tree (17 Implement leaves incl. a real 3-level branch at 1.2.1/1.2.2, 2 Testing leaves) and the dashboard's own dark-ocean theme tokens, so they're a fair side-by-side comparison. Every one is fully interactive — click around.
